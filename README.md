# 🌦️ Weather App

A simple **Weather App** built using **Python**, **Tkinter**, and the **OpenWeatherMap API** as part of the **Oasis Infobyte Python Programming Internship**.

## Features

- Search weather by city name
- Displays current temperature
- Displays weather condition
- Displays humidity
- Displays wind speed
- User-friendly Tkinter GUI
- Input validation
- Clear and Exit buttons

## Technologies Used

- Python 3
- Tkinter
- Requests
- OpenWeatherMap API

## Installation

Install the required library:

```bash
pip install requests
```

## How to Run

```bash
python weather_app.py
```

Enter a city name and click **Get Weather** to view the current weather details.
